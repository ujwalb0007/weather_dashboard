# 🌦️ Live Weather Dashboard

A sleek, real-time **Command-Line Weather Tracker** built with Python.  
Fetches live weather forecasts using the **OpenWeatherMap API**, displays temperature trends, and exports structured reports.

---

## 🚀 Features

✅ Fetches **current & 7-day forecast** data for any city  
✅ Displays temperature, humidity, and weather description  
✅ **Plots temperature trend** graph with `matplotlib`  
✅ Saves reports as CSV files for analysis  
✅ Uses `.env` to keep API keys secure  
✅ Lightweight & runs directly in your terminal  

---

## 🧠 Tech Stack

| Component | Technology |
|------------|-------------|
| Language | Python 3 |
| API | [OpenWeatherMap API](https://openweathermap.org/api) |
| Data Handling | `pandas` |
| Visualization | `matplotlib` |
| Configuration | `python-dotenv` |
| Networking | `requests` |
